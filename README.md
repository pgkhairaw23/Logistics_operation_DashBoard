Powerbi- Dashboard is designed to support logistics performance monitoring and operational decision-making by providing a centralized view of order demand, delivery efficiency, vehicle utilization, and hub performance.
🚚 Trucking Logistics – Operations Overview Dashboard

This Operations Overview Dashboard provides a comprehensive view of trucking and logistics performance, helping monitor order volume, delivery efficiency, vehicle utilization, and hub-level operations.

📊 Key Performance Indicators

The dashboard highlights the following important metrics:

Total Orders: 28.0K
On-Time Delivery Rate: 79.6%
Orders Delivered: 27.7K
Average Delivery Time: 35.78 minutes
Cancelled Orders: 0.01%
📈 Order Trends

The Total Orders by Month chart tracks monthly order volumes throughout the year, making it easy to identify fluctuations, high-demand periods, and changes in overall order activity.

🏢 Hub Performance

The Average Delivery Time by Hub visual compares delivery performance across:

Fort Worth Hub
San Antonio Hub
Houston Hub
Dallas Main Hub
Austin Hub
El Paso Hub

This helps identify differences in delivery times across operational locations.

🚛 Vehicle Analysis

The Orders by Vehicle Type chart shows order distribution across:

Van: 17.5K
Truck: 6.5K
Pickup: 2.8K
Box Truck: 1.1K

This provides insight into vehicle usage and the types of vehicles handling the highest order volumes.

🗺️ Hub Order Distribution

The HubName treemap displays the proportion of total orders handled by each hub, allowing users to quickly compare operational workloads across locations.

🔎 Interactive Analysis

The dashboard includes filters for:

Year
Month
Order Status

These filters allow users to drill down into specific periods and order statuses for more focused analysis.
